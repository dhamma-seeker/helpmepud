พิมพ์ไทยเพื่อแปลเป็นอังกฤษไปตอบเพื่อน หรือสลับเป็น "อังกฤษ → ไทย" แล้ววางข้อความของเพื่อนเพื่อให้แปลให้อ่าน

กดไมค์ พูดไทย แล้วแอปจะแปลเป็นอังกฤษและอ่านออกเสียงให้ เมื่อเพื่อนตอบ กดไมค์ฝั่งเพื่อนเพื่อแปลกลับเป็นไทย

เบราว์เซอร์นี้ไม่รองรับการฟังเสียง ใช้ปุ่มไมค์บนคีย์บอร์ดของมือถือแทนได้

ถามได้เลย เช่น "ถ้าอยากปฏิเสธคำชวนแบบสุภาพ พูดว่าอะไรดี" หรือ "คำว่า เกรงใจ ภาษาอังกฤษใช้คำไหน"

key เก็บไว้ในเครื่องนี้เท่านั้น (localStorage) และถูกส่งไปที่ openrouter.ai โดยตรง ไม่ผ่านเซิร์ฟเวอร์อื่น แต่ละอุปกรณ์ต้องใส่เอง

พิมพ์ model id ตามหน้า openrouter.ai/models ได้เลย

iPhone/iPad: เปิดใน Safari แล้วกดแชร์ → เพิ่มลงในหน้าจอโฮม
Android/คอมพิวเตอร์: ใช้เมนูเบราว์เซอร์ "ติดตั้งแอป"
