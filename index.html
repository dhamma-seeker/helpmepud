เบราว์เซอร์นี้ไม่รองรับการฟังเสียง ใช้ปุ่มไมค์บนคีย์บอร์ดของมือถือแทนได้

key เก็บไว้ในเครื่องนี้เท่านั้น (localStorage) และถูกส่งไปที่ openrouter.ai โดยตรง ไม่ผ่านเซิร์ฟเวอร์อื่น แต่ละอุปกรณ์ต้องใส่เอง

แยกโมเดลตามงานได้ เช่นแปลใช้ตัวเร็วและถูก ส่วนหัวข้อ MCP ต้องเป็นโมเดลที่รองรับเครื่องมือ กดชื่อโมเดลที่มุมขวาบนของแอปเพื่อสลับได้จากทุกหน้า รายชื่อโมเดลดึงสดจาก OpenRouter

รายการเสียงขึ้นกับเครื่องที่ใช้ (iPhone, Android และคอมพิวเตอร์มีชุดเสียงต่างกัน) ระบบไม่บอกเพศของเสียง ให้กดฟังตัวอย่างแล้วเลือกเอง

การตั้งค่าเสียงจำแยกตามอุปกรณ์ เสียง AI จะเล่นซ้ำจากแคชโดยไม่เสียเงินเพิ่มเมื่อกดฟังประโยคเดิม

รองรับ MCP แบบ Streamable HTTP ที่ไม่ต้องล็อกอิน และเซิร์ฟเวอร์ต้องเปิด CORS ให้เว็บเรียกได้

iPhone/iPad: เปิดใน Safari แล้วกดแชร์ → เพิ่มลงในหน้าจอโฮม
Android/คอมพิวเตอร์: ใช้เมนูเบราว์เซอร์ "ติดตั้งแอป"
